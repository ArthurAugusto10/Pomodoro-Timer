
# Pomodoro Timer App ⏱️

Aplicativo de produtividade desenvolvido em Flutter, utilizando
a técnica Pomodoro para organizar sessões de foco e descanso.

## Funcionalidades

- Cronômetro Pomodoro de 25 minutos
- Pausas curtas e longas
- Gerenciamento de tarefas
- Histórico de sessões concluídas
- Persistência local de dados
- Dashboard de produtividade
- Gráfico semanal de ciclos de foco
- Interface Cyberpunk Neon
- Imagens de fundo personalizadas

## Tecnologias utilizadas

- Flutter
- Dart
- Material Design 3
- SharedPreferences

## Como executar

1. Clone o repositório:

   git clone https://github.com/ArthurAugusto10/Pomodoro-Timer.git

2. Entre na pasta do projeto:

   cd Pomodoro-Timer

3. Instale as dependências:

   flutter pub get

4. Execute:

   flutter run

Para executar no navegador:

   flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8080

## Sobre o projeto

O Pomodoro Timer App é um projeto de estudo desenvolvido
para praticar Flutter, gerenciamento de estado, persistência
local e construção de interfaces modernas.
